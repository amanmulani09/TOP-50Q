## 📁 Repo Convention

```
TOP-50Q/
├── README.md                  ← this index; update the table per company
├── companies/
│   └── <company-name>.md      ← one file per company (kebab-case)
└── templates/
    └── company-template.md    ← copy this to start a new company
```

## ➕ Adding a New Company

1. `cp templates/company-template.md companies/<company-name>.md`
2. Fill in the metadata table, priority topics, and questions.
3. Add a row to the index above.
4. Update **Status** as prep progresses; fill **Result** after the round.
